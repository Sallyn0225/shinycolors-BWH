# AGENTS

## Design Context

Strategic product context lives in [`PRODUCT.md`](./PRODUCT.md) (register, users, positioning, anti-references, principles).

Visual system lives in [`DESIGN.md`](./DESIGN.md) (tokens, components, do’s and don’ts). Machine-readable sidecar: [`.impeccable/design.json`](./.impeccable/design.json).

Live variant mode is preconfigured in [`.impeccable/live/config.json`](./.impeccable/live/config.json) (`index.html`).

When changing UI, prefer existing CSS variables in `src/styles.css` and keep the Color Roster Desk posture: raw cm first, Signal Blue for controls only, identity colors on cast marks — never a beauty scoreboard.
